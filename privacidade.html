Política de Privacidade

Nilma Contabilidade. Atualizada em 23 de setembro de 2026.

Esta política vale para o sistema interno de controle de documentos da Nilma Contabilidade (Nilma Protocolos e Cobrança de Documentos) e para a integração dele com a conta de e-mail do escritório, nilmacontabilidade@gmail.com.

Quem usa

O sistema é de uso interno. Só a equipe do escritório, com login próprio, tem acesso a ele. A única parte aberta é a página de guias que cada cliente pode receber, descrita mais abaixo, que mostra só as informações daquele cliente.

O que o sistema acessa no Gmail

  • Leitura dos e-mails recebidos na caixa do escritório, para reconhecer quando um cliente enviou extrato bancário, comprovante ou aplicação e marcar isso no controle mensal.
  • Envio de e-mails de cobrança de documentos aos clientes, a partir da própria caixa do escritório, e de avisos internos para a equipe. Se o escritório ligar, também saem sozinhos o lembrete de documentos em dias combinados do mês e o comprovante de cada entrega de guia.

O sistema não acessa nenhuma outra conta de e-mail além da do escritório.

O que é guardado

  • No controle mensal: remetente, assunto, data e nome dos arquivos anexados dos e-mails de clientes.
  • Os anexos são salvos no Google Drive do escritório somente quando alguém da equipe pede.
  • Os dados ficam no Google Firebase e no Google Drive do escritório.

O que não é feito

  • Os dados não são vendidos, cedidos nem compartilhados com terceiros.
  • Os dados não são usados para publicidade.
  • Os dados não são usados para treinar modelos de inteligência artificial.

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

A página de guias do cliente

Alguns clientes recebem do escritório um endereço próprio, sem senha, onde veem as guias dos últimos meses, o código para pagar, o comprovante de entrega e os documentos que ainda falta enviar. Quem tem o endereço vê essas informações, por isso ele não deve ser repassado; se isso acontecer, peça ao escritório para trocar o endereço, e o antigo deixa de funcionar na hora.

Nessa página ficam registrados: quando ela foi aberta, quando um código foi copiado ou uma guia foi vista, o nome digitado ao confirmar o recebimento de uma guia e, se o cliente ligar o lembrete de vencimento, o endereço de notificação daquele celular. Esses registros servem para o escritório saber que a guia chegou e para enviar o lembrete; não são usados para outra finalidade nem compartilhados.

Quando o cliente toca em "Já paguei esta guia", fica registrado que ele avisou o pagamento, com a data e a hora. É um recado para o escritório não cobrar de novo — não vale como comprovante e não é conferido com o banco.

Quando o cliente escreve no campo de falar com o escritório, a mensagem e o nome digitado ficam guardados até alguém da equipe ler e responder.

A página guarda no próprio aparelho (no navegador) o que você já abriu e o aviso de instalação que já foi fechado, para não repetir. Isso não sai do seu celular e some se você limpar os dados do navegador.

A página usa a fonte do próprio aparelho e não baixa fontes nem ícones de outros sites; de fora, ela carrega só o Firebase do Google (banco de dados e, se o cliente ligar o lembrete, as notificações). O Firebase enxerga o endereço de IP do aparelho, como em qualquer site.

O cliente também pode enviar um documento (PDF ou foto) por essa página. O arquivo passa pelo Firebase só até o computador do escritório guardá-lo no Google Drive do escritório; depois é apagado do Firebase.

O protocolo de entrega impresso traz um código. Quem tem o código vê, na mesma página, o que foi registrado naquele protocolo (documentos, datas e nome de quem recebeu), sem assinatura e sem localização, para conferir se o papel é verdadeiro.

Por quanto tempo

As informações ficam guardadas enquanto forem necessárias à prestação dos serviços contábeis e ao cumprimento de obrigações legais. Pedidos de envio concluídos são apagados da fila depois de 30 dias.

Seus direitos

Conforme a Lei Geral de Proteção de Dados (Lei 13.709/2018), você pode pedir acesso, correção ou exclusão dos seus dados. A autorização de acesso ao Gmail pode ser revogada a qualquer momento em myaccount.google.com/permissions.
